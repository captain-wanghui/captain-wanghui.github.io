# 项目相关工具介绍
在本项目的开发过程中，我们使用了一系列实用的工具，以下是对这些工具的简要介绍：

## 开发框架与开发工具
### Jekyll
Jekyll 是一个简单的静态站点生成器，它可以将 Markdown 或 HTML 文件转换为静态网页。我们使用 Jekyll 来构建项目的博客系统，它具有简洁的配置和灵活的模板系统，能够帮助我们快速搭建出美观且功能完善的博客页面。

### Trea
Trea 是一个基于 AI 的编程工具，它可以帮助我们快速编写代码。Trea 具有强大的代码生成和自动补全功能，能够根据我们的需求自动生成代码，减少了编写代码的时间和工作量。同时，Trea 还提供了代码调试和错误修复功能，能够帮助我们及时发现和修复代码中的错误。

## 版本控制与网站托管
### Git
Git 是一个分布式版本控制系统，它可以帮助我们管理项目的代码变更。通过 Git，我们可以方便地进行代码的提交、分支管理和合并操作，确保项目的代码能够有序地进行开发和维护。

### GitHub
GitHub Pages 是 GitHub 提供的一个静态网站托管服务，我们将项目的博客页面托管在 GitHub Pages 上，以便用户能够通过互联网访问我们的博客。通过 GitHub Pages，我们可以实现博客的持续更新和访问，同时还可以利用 GitHub 的其他功能，如问题跟踪、代码审查等。

# AI编程工具的使用
此项目中，借助Trea完成了Jekyll框架的搭建以及相关板块的代码编写，在上传仓库等操作中也使用Trea内置的智能体对命令行等进行操作，大幅减少了对编程能力和计算机命令行操作的依赖，提升了项目的效率。

## 项目的AI驱动与Trea的使用
此项目中，Trea主要用于以下几个方面：
1. 代码自动生成：Trea可以根据我们的指令自动生成代码，减少了手动编写代码的时间和工作量。
2. 代码调试与错误修复：Trea具有强大的代码调试和错误修复功能，能够帮助我们及时发现和修复代码中的错误。
3. 命令行操作的自动化：Trea可以根据我们的指令自动执行命令行操作，如安装依赖、运行项目等，减少了手动操作的错误风险。

以上就是本项目所使用的一些主要工具，它们在项目的开发和维护过程中发挥了重要的作用。如果你对这些工具感兴趣，可以通过相关的官方网站了解更多详细信息。
